حلقات أنوار الهداية - حزمة الرفع على مخدم

محتويات الحزمة
  index.html            التطبيق كاملاً في ملف واحد
  manifest.webmanifest  يجعل التطبيق قابلاً للتثبيت من كروم
  sw.js                 يحفظ نسخة تفتح عند ضعف الاتصال
  icons/                أيقونات التطبيق

الرفع
  ارفع المجلد كما هو إلى أي استضافة ملفات ثابتة (Nginx أو Apache أو GitHub Pages أو Netlify أو Cloudflare Pages).
  يجب أن يكون الرابط https ليظهر خيار «تثبيت التطبيق» في كروم.
  افتح الرابط ثم من قائمة ⋮ اختر «تثبيت التطبيق».

حفظ البيانات (مهم)
  خارج Claude تُحفظ البيانات داخل متصفح كل جهاز فقط، ولا تُشارَك بين المشرفين والمعلمين.
  استخدم «نسخة احتياطية (JSON)» و«تصدير كل البيانات (Excel)» من الإعدادات بانتظام.
  للمشاركة الحقيقية بين عدة أجهزة يلزم قاعدة بيانات على المخدم، وهي غير مضمّنة في هذه الحزمة.

مكتبة Excel ومحرف الخطوط تُحمَّلان من الإنترنت (cdnjs وGoogle Fonts). بدون إنترنت يعمل التطبيق بخط النظام ويتعطل تصدير Excel.

==== الربط مع Supabase (بيانات مشتركة + تسجيل دخول) ====
1) في Supabase: SQL Editor ← New query ← الصق محتوى supabase_setup.sql ← Run.
2) Authentication ← Providers ← Email: يمكنك إيقاف "Confirm email" لتسهيل أول دخول.
3) ارفع هذا المجلد على Netlify (Drop). افتح الرابط وأنشئ حساباً: أول حساب يصبح "مشرفاً مسؤولاً" تلقائياً.
4) بعد ذلك يسجّل الآخرون حساباتهم، وتمنحهم من الإعدادات ← المستخدمون الصلاحية (عرض فقط / موظف / مشرف مسؤول).
ملاحظة: بيانات النسخة المحلية القديمة لا تنتقل تلقائياً. إن كانت لديك بيانات حقيقية فيها فتواصل لنقلها.
