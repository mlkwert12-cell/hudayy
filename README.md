# حلقات أنوار الهداية — أدوات التشغيل (مستودع خاص)

| المجلد | المحتوى |
|---|---|
| `sql/` | ملفات قاعدة البيانات بالترتيب: 01 ← 02 ← 03 (ثم 02b و02c من عندك) |
| `tests/` | `rls_and_session.sql` و`points_client.js` و`scale_bench.sql` (على قاعدة تجريبية فقط) |
| `loadtest/` | اختبار الحمل k6 + بذر المستخدمين |
| `backup/` | سكربتات النسخ الاحتياطي واختبار الاستعادة |
| `monitoring/` | مقطع Sentry وأداة إدراجه |
| `docs/` | التوثيق الكامل |

**ملف التطبيق** (`index.html`, `sw.js`, `manifest.webmanifest`, `icons/`) يبقى في مستودع GitHub Pages فقط.
